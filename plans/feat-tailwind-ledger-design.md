# Tailwind CSS で本体を帳票・明細書風に作り直す (#22)

## 方向性

生成りの紙色の背景、細い罫線、桁をそろえた数字（`tabular-nums`）、差し色は1色。グラデーション・影・角丸のカードは使わない。

## 構成

- 左に入力（本人・配偶者・扶養親族・障害とひとり親）、右に結果の2列。`md` 未満は1列
- 結果: 手取りの大きな数字 → 手取り・社会保険料・税金の積み上げ帯（金額と割合つきの凡例）→ 明細の表4つ → 会社負担の注記 → 所得税の使いみち（行ごとの横棒つきの表）
- 明細の表の中身は `src/utils/ledger.ts` の純粋関数で組み立てる
- 帯グラフの割合は `src/utils/stack.ts`、金額と割合の表記は `src/utils/format.ts`

## スタイル

- Tailwind CSS v4（`@tailwindcss/vite`）。コンポーネントに `<style>` は書かない
- 色はライト・ダーク両方のトークンを `src/styles.css` だけに置き、ユーティリティから使う
- グラフの色は dataviz の既定パレットの先頭3色。紙色の背景に対して検証スクリプトを通した（ライトでは橙と緑が 3:1 未満なので、凡例に金額を必ず出す）
