# ふるさと納税ページの見た目を本体とそろえる (#24)

- `<style>` をやめ、本体と同じトークン（`src/styles.css`）と部品（`NumberField`・`FormSection`・`LedgerTable`）を使う
- `NumberField` に任意の `placeholder` と `hint`（入力欄の下の補足）を足す
- 結果は、上限額の大きな数字 → 所得税率と計算式 → 計算の内訳の表 → 速算係数表（該当する行を左の差し色で示す）
- 速算係数表の強調行は税率が0%のとき存在しないので、所得税率は計算式の行にも明示する
- 本体とふるさと納税ページの間にリンクを置く
- 作り直しの前後のビルドを並べ、同じ入力で各項目の数値が一致することを確かめる
