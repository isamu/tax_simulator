# 住宅ローン控除の計算 (#46)

令和8年分の所得税・令和9年度分の住民税。この PR は計算だけで、入力フォームとシェア用 URL は次の PR。

- `src/utils/housingLoan.ts`（純粋関数）
  - 控除額 = 年末残高 × 0.7%（100円未満切り捨て）。上限は新築／中古 × 性能4区分 × 入居年（令和4〜5／6〜7／8）× 子育て・若者夫婦世帯で、国税庁 No.1211-1・1211-3 の表のまま
  - 合計所得 2,000万円超は 0
  - 所得税から引き、残りを住民税所得割から引く。住民税の上限は課税総所得の5%（最大97,500円）
- `taxes()` に組み込む
  - 復興特別所得税は控除後の所得税にかける
  - 所得税の使いみちは控除後の所得税で按分
  - ふるさと納税の上限額は控除前の所得割で計算（地方税法37条の2）
- 明細に「住宅ローン控除」の欄（所得税から・住民税から・引き切れない分、合計が控除額）。ローンがあるときだけ出す
- 対象外: 令和3年以前の入居、40〜50㎡の住宅の所得要件（1,000万円）、補助金・贈与の差し引き、建築確認が令和5年までの「その他の住宅」の例外、住宅ローン控除があるときのふるさと納税の上限の下がり方
