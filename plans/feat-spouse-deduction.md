# 配偶者控除・配偶者特別控除 (#16)

- 人的控除は `src/utils/deductions.ts` に純粋関数として置き、所得税と住民税の額を `PersonalDeduction` で一緒に返す
- 配偶者の合計所得は、給与収入から令和8年分の給与所得控除を引いて求める（給与のみを前提とする）
- 本人の合計所得（給与所得）の区分: 900万以下 / 950万以下 / 1,000万以下 / 超（適用なし）
- 所得税の配偶者特別控除は国税庁 No.1195 の表、住民税は地方税法 第314条の2 第1項第10号の2 の計算式をそのまま実装する（住民税側は表の形の一次資料がないため）
- 住民税の 2/3・1/3 は分子と分母の整数で計算する。浮動小数点の誤差で1万円単位の切り上げが1段ずれるのを避けるため
- `Household` に `spouse: Spouse | null` を足す
