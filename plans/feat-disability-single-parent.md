# 障害者控除・寡婦控除・ひとり親控除 (#20)

- `Household` に `selfDisability`（本人の障害: なし / 障害者 / 特別障害者）、`familyDisabilities`（配偶者・扶養親族のうち障害者 / 特別障害者 / 同居特別障害者の人数）、`singleStatus`（なし / 寡婦 / ひとり親）を足す
- 控除額（所得税 / 住民税）: 障害者 27万 / 26万、特別障害者 40万 / 30万、同居特別障害者 75万 / 53万、寡婦 27万 / 26万、ひとり親 35万 / 30万
- 寡婦・ひとり親は本人の合計所得（給与所得）500万円以下のときだけ適用する。それ以外の要件は入力した人が満たしているものとする
- 対象外: ひとり親控除の引上げ（所得税は令和9年分、住民税は令和10年度分から）、勤労学生控除
